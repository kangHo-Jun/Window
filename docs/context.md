## 최신 사용자 방향 — 기존 기획보다 우선 (2026-10-08)

- A03 최신 상태: 사용자 키 설정 후 Claude Haiku 5.5(low) 실제 외풍 상담 7턴 성공. 공간 수정·기간/수량·전달 초안 확인. 테스트 17개·빌드 통과. 다음은 답변 간결화·경로 확대, 제품/가격 근거 확보 및 접수 연결. UI 후순위, baseline 유지.

- 최신 승인: 외풍 목업의 상담 내용·흐름 통과. UI는 현재 관심·평가 대상이 아니므로 디자인 작업을 확대하지 않는다. 다음은 A03 실제 AI 상담 한 경로 연결이며, API 상태·비용 제한을 먼저 확인한다.

- 1차 봇의 목표는 고객이 창호 문제와 해결 방향을 이해하고 대산의 실제 확인·상담 역량을 신뢰하도록 하는 것이다. 제품 선택 기준과 현장 확인 계획을 핵심 결과로 제공한다.
- 경험 순서: 목적 선택→필요한 질문과 설명→현장별 선택 기준·확인 계획→필요시 가견적→담당자 상담. 가견적 없이 유효 상담으로 연결되는 것도 성공이다. 가격 우선 고객의 빠른 경로도 유지한다.
- UI는 기본 구성으로 두되 답변에 따라 설명·계획이 달라지고 상담 정리가 누적되도록 한다. 결과를 봐도 대화·수정을 유지한다. 고정 설문, 일률적 LX 추천, 근거 없는 현장 개선율과 인위적 대기를 개선한다.
- 초기 B2B, 이후 B2C 확장. 실제 영업은 자료 상담→구매 의사 확인→실측→정식 견적. 공급만 필요한 B2B와 시공 검토 고객의 책임 범위를 구분한다.
- LX 완성창 중심 설명은 확인된 자료를 사용한다. 제품·제작 특징, 대산 또는 협력업체의 실제 공급/시공 절차, 사후 대응 책임을 각각 입증한다.
- 최신 개선안: `planning/current/2026-10-08-problem-solving-chatbot-plan.md`. 상위 `website-prd-outline.md`, 상세 `chatbot-estimate-prd.md`와 함께 구현 기준으로 사용한다. 기존 완성 단계 평가서는 입력/가격/저장 품질 참고다.
- 검증된 구조 문제: 결로 추가 답변 3종이 동일 진단 결과로 귀결되는 로컬 함수를 재현했다. 상세 답이 실제 안내와 확인 계획을 바꾸도록 개선해야 한다.
