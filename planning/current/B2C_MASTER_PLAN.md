# 2차 B2C 사이트 개발 계획과 재개 인계

최종 갱신: 2026-10-12
**상태: 사용자 지시로 개발 중단. 재개 요청 전에는 구현·AI 호출·배포를 진행하지 않는다.**

## 범위와 현재 위치

일반 소비자가 창호 문제를 이해하고 LX 완성창의 선택 기준을 확인한 뒤 대산에 상담하도록 돕는 독립적인 B2C 웹사이트다. 1차 인테리어 업자용 B2B 사이트와 다른 사이트이며, 1차의 후속 기능 추가가 아니다. 지금까지 논의·개발한 챗봇, RAG, 음성 입력, AI 비용 통제는 모두 2차에 속한다.

**현재 위치: 외풍 대표 상담의 개발용 구현·실제 AI 검증까지 진행. 제품·가격·접수·운영 비용 제어·정식 공개는 미완료.**

챗봇 중심 홈페이지인지 B2C 홈페이지 내 임베드인지는 재개 후 결정한다. 기존 문서의 B2B 우선·B2C 확장 표현은 폐기된 통합 가정이다. B2B 관련 과거 입력·비교 요구는 1차 확정 요구사항으로 자동 이전하지 않는다.

## 알려진 문제와 출시 전제

- 운영용 공유 비용 통제는 아직 없다. 개발 제한은 프로세스 60회·세션 12회·동시 2회·입력 1,000자·출력 1,600토큰이며 메모리에 저장된다. 이를 월 예산 차단으로 취급하지 않는다.
- 신규 화면/API는 개발 전용이며 production에서 404를 반환하도록 구성했다는 검증 기록이 있다. 기존 운영 홈페이지 복구와 신규 챗봇 공개는 별개다.
- 기존 운영 /api/chat의 429 원인은 미해결이다. 과거 Gemini 402는 신규 상담의 Claude 전환 후 재개 선행 조건이 아니다. 서로 같은 원인이라고 가정하지 않는다.
- 기존 앱 평가에서 기간/수량 오인, 폼/챗봇 가격 불일치, 제품 매핑·미매칭 기본가격, 고정 개선 수치, 내부 전략 노출, 시트 중복 append를 발견했다. 신규 상태 관리 개선만으로 기존 앱 전체 문제가 해결된 것은 아니다.
- 제품 근거·가격·보증·접수와 Firestore 승인 지식은 신규 상담에 아직 연결되지 않았다. 지금 검색 원본은 승인된 외풍 상담 절차이며 제품 성능 증거가 아니다.
- 일/월 예산, 실제 판매 사양, 고객 응대 범위·보관 기준, 최종 디자인·공개 방식은 미정이다.

## 재개 실행 안내

사용자가 2차 재개를 명시하면 이 문서→HANDOFF 최신 기록→README-A03→관련 코드 순서로 확인한다. 실제 외부 호출은 설정과 비용 제한 확인 뒤 수행한다.

앱 폴더에서 기록된 명령:

```sh
node scripts/test-consultation.mjs
npm run build -- --webpack
CONSULTATION_DEV_ENABLED=1 npm run dev -- --hostname 127.0.0.1 --port 3013
```

마지막 명령은 재개 후 로컬 시험용이다. 이번 중단 정리에서는 실행하지 않았다. /consultation에서 외풍 설명→중간 질문→공간 수정→1~3개월→미정→예산 문의→전달 초안의 경로를 확인한다. 기존 7턴 시험이 이미 성공했음을 알고 회귀 검증으로 수행한다.
