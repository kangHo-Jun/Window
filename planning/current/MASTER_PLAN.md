## 두 사이트의 구분

**1차 B2B와 2차 B2C는 완전히 다른 웹사이트다. 하나의 사이트를 단계적으로 확장하는 계획이 아니다.**

| 구분 | 1차 B2B 사이트 | 2차 B2C 사이트 |
|---|---|---|
| 대상 | 인테리어 업자 중심, 일반 소비자도 이해·문의·추천 가능 | 일반 소비자 |
| 현재 상태 | 메뉴·본문 구성 승인, 구간별 원고·자료 준비표 작성 | 사용자 지시로 개발 중단·재개 인계 정리 완료 |
| 독립 기획 | [1차 사이트 구성안](B2B_SITE_PLAN.md)에서 메뉴·콘텐츠·상담 흐름 관리 | 아래 전용 계획으로 관리 |
| 챗봇·AI·음성·비용 제어 | 현재 범위에 포함하지 않음 | 지금까지의 관련 기획·구현 전체가 여기에 속함 |
| 다음 행동 | 자료 선별 → 원고·FAQ 검수 (사이트 제작은 별도 요청 전 보류) | 명시적인 2차 재개 지시까지 현 상태 보존 |

## 1차 사이트 방향 — 사용자 확정 2026-10-13

**왜 대산에서 LX 완성창과 건축자재를 함께 구매해야 하는가를 설명하는 홍보·상담형 웹사이트.**

[머물고 싶은 집](https://www.homewindows.co.kr/) 정도의 제품 소개·시공 사례·신뢰·상담 구성을 기준으로 삼고, 대산만의 구매 이유를 더한다. 인테리어 업자만 사용하는 폐쇄형 업무 시스템이 아니라 일반 소비자도 쉽게 이해할 수 있는 공개 사이트다.

### 대상과 기대 반응

| 대상 | 방문 후 이해하고 행동할 내용 |
|---|---|
| 핵심: 인테리어 업자 | 창호와 목재 등 여러 건축자재를 대산에서 함께 구매하면 조달이 편하고 비용도 줄일 수 있겠다고 판단해 거래·구매 상담 |
| 함께 고려: 일반 소비자 | 대산이 LX 창호도 취급하고 다른 자재와 함께 구매 혜택이 있다는 점을 이해해 직접 문의하거나 담당 인테리어 업체에 대산 이용을 제안 |

### 핵심 메시지

1. **LX 완성창 취급:** 대산에서 창호도 구매할 수 있다는 사실을 명확하게 알린다.
2. **35년 전통과 신뢰:** 건축자재 판매 경험과 지속성을 대산 선택의 이유로 설명한다. 창호 제조·시공 경력 35년으로 바꾸지 않는다.
3. **올인원 자재 구매:** 창호뿐 아니라 목재 등 여러 건축자재를 한곳에서 함께 구매하는 편의를 보여준다. 올인원은 자재 구매 의미이며 통합 인테리어 시공까지 자동으로 포함하지 않는다.
4. **같은 공사 건의 목자재·기초자재 10% 할인:** 2026-10-15 사용자 설명에 따라 LX 창호 구매와 연결해 해당 공사 건의 목자재·기초자재 구매 혜택으로 안내한다. 할인율은 10%다. 창호 가격은 할인 대상에서 제외한다. 목자재의 세부 품목, 기준 가격·시점·제외 조건은 추후 확인한다. 모든 자재에 적용되는 할인으로 확대하지 않는다.
5. **왜 대산인가:** LX 제품의 장점과 대산에서 구매하는 장점을 연결해 설명하고 문의·구매 상담으로 이어준다.

### 포함할 내용과 제외 범위

- 포함: 제품 소개, 시공 사례, 대산 소개와 35년 신뢰, 다른 자재와 함께 구매하는 편의·혜택, 간단한 문의·상담 안내.
- 제외: 복잡한 온라인 견적 입력·계산 절차, AI 챗봇·음성 상담·AI 진단. 이 사이트에서 고객에게 상세 견적 작성을 요구하지 않는다.
- 온라인 주문·결제·회원 업무 시스템은 이번 설명으로 확정된 기능이 아니다. 문의·구매 상담 연결이 현재 목표다.
- 2차 B2C AI 사이트와 개발 범위·진행 상태를 분리한다. 1차에 소비자가 방문한다는 이유로 2차 챗봇 기능을 포함하지 않는다.

### 1. 서비스와 구매 흐름

**사이트 방문 → 창호 전담 직원 상담 → 고객의 실측 요청 → 협력업체 실측 → 견적서 제공 → 주문.**

사이트의 첫 행동은 상담이다. 고객의 관심과 신뢰를 실측 요청으로 이어주는 것이 핵심이며 사이트에서 주문·계약을 먼저 완료하도록 요구하지 않는다. 견적은 상담·실측 후 제공한다.

핵심 구매 이유는 ‘같은 품질의 LX 완성창을 구매하면서 같은 공사에 필요한 목자재 비용을 줄일 수 있다’이다. 35년 건축자재 판매 경험은 이를 뒷받침하는 신뢰 근거다. 할인율 10%와 같은 공사 건·창호 금액 제외는 사용자 확인 사항이며, 할인 세부 조건은 미정으로 남긴다.

### 2. 채널과 콘텐츠

| 유입 채널 | 전달할 내용 |
|---|---|
| 기존 거래처에 영업직원이 링크 전달 | 대산의 LX 창호 취급과 같은 현장 목자재 구매 혜택을 알려 창호 상담 유도 |
| 네이버 검색·블로그 | 창호 제품·사례로 관심을 모으고, 대산의 구매 혜택·35년 신뢰로 사이트와 상담 연결 |

첫 화면은 LX 창호의 제품·시공 이미지와 구매 상담을 중심으로 한다(2026-10-15 사용자 정정). 함께 구매하는 할인 혜택은 하단 구매 이유 구간에서 대산의 35년 업력·상담 지원과 함께 설명한다. 할인 상세 조건이 확정되기 전 실제 공개 문구를 최종 확정하지 않는다.

사용자 확인 자료 현황:

| 자료 | 상태와 사용 원칙 |
|---|---|
| 매장·창고·자재 사진 | 보유, 정리·선별 필요. 최신 랜딩 메인·ALL IN ONE 구간에는 배치하지 않음 |
| 대산 창호 시공 사진·사례 | 2026-10-26 사용자 확정: 대산 사진 없음. 엑셀은 실제 현장 이력. LX 공식 사례 사진 23장·6개 사례·영상 2개로 검토본 준비, 대산 이력은 별도 목록으로 표시 |
| LX 공식 제품 사진·카탈로그 | 보유, 실제 취급 모델 및 활용 범위 확인 후 사용 |
| 거래처 후기·추천 | 보유, 내용·게시 동의 확인 후 사용 |
| 영림도어 전국 판매 1위 증빙 | 없음. 해당 문구는 게시 보류 |

보유 자료의 원본을 이번에 검수한 것은 아니다. 자료가 있다는 사용자 답변과 웹 게시 준비 완료를 구분한다. 별도 도어 주문·납기 서비스 기획은 이 사이트 범위에 포함하지 않는다.

### 3. 실행과 상담 운영

- 담당자는 창호 전담 직원이다.
- 접수는 전화, 카카오톡, 연락처를 남기는 상담 신청의 세 가지를 모두 제공한다.
- 상담 신청을 남긴 고객에게는 전담 직원이 연락하고, 상담 후 의향에 따라 실측 요청을 받는다.
- 실제 번호·카카오톡 연결 주소·신청 양식 필수 항목·응대 시간·회신 기준·개인정보 처리 조건은 화면 구체화 때 확보한다. 현재 답변으로 특정 응대 속도를 약속하지 않는다.
- 복잡한 온라인 견적·AI 챗봇·음성 상담은 1차에 포함하지 않는다. 2차 중단 유지.

### 4. 평가 기준

**핵심은 상담에서 실측 요청으로 이어지는 성과다.**

| 지표 | 의미 |
|---|---|
| 실측 요청 건수 | 실제 영업 기회가 얼마나 생겼는가 |
| 상담 → 실측 요청 전환율 | 상담한 고객/공사 건 중 실측 요청으로 이어진 비율 |
| 상담 건수 | 각 채널에서 얼마나 상담을 시작했는가. 보조 지표 |
| 최종 주문 건수 | 실측·견적 이후 실제 구매로 이어졌는가. 보조 지표 |

집계 설계 제안: 동일 고객·동일 공사의 전화/카카오톡/신청을 하나의 상담 건으로 연결하고, 최초 유입·상담일·실측 요청일·견적 제공·주문 여부를 전담 직원이 기록한다. 버튼 클릭만으로 상담이나 실측 요청이 발생했다고 계산하지 않는다. 실측 요청과 실측 완료를 구분한다. 전환율은 같은 상담 집단과 관찰 기간으로 계산하며 목표 건수·비율·평가 주기는 초기 기준값 확보 후 정한다.

## 관리 규칙

- 작업 시작 시 대상 사이트를 확인한다. 2차는 재개 지시 전 구현·AI 호출·배포를 진행하지 않는다.
- 각 사이트의 목표·작업 목록·상태를 독립 관리한다. 이 문서는 두 사이트를 찾는 최상위 안내다.
- 작업 종료 시 해당 전용 계획과 HANDOFF를 갱신한다. 주기적 실행 없음.
- 완료는 파일/검증 근거로 판정하고 문서 작성·로컬 검증·운영 공개를 구분한다.
- 기존 코드와 폴더는 이번에 이동하지 않았다. 물리적 분리와 재사용 여부는 1차 요구사항 확인 후 별도 결정한다.

전용 고정 작업: 창호 웹사이트 마스터 플랜. 원본은 이 파일이며 채팅 과거 답변은 당시 기록이다.
