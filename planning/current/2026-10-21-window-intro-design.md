# 1차 사이트 첫 화면 — 반장이 검은 화면을 밀어 여는 인트로 설계

작성: 2026-10-21 · 상태: 사용자 설계 승인, HTML 시안 단계 · 상위 기준: `B2B_SITE_PLAN.md`

## 1. 배경과 목적

Threads의 Huy Phan 포트폴리오 영상(일러스트 캐릭터가 검은 화면을 밀어 열며 이름이 드러나는 인트로)에서 착안했다. 창호 회사 사이트가 "창을 열며" 시작하면 연출이 곧 업종의 이야기가 된다.

목적은 첫 방문 3초 안에 "창호를 다루는 대산"을 각인시키고, 곧바로 기존 메인(창호가 주인공인 첫 화면)으로 넘기는 것이다. 로딩을 늘리거나 내용을 가리는 장치가 되어서는 안 된다.

## 2. 확정 사항 (사용자 선택)

- 적용 위치: 1차 B2B 사이트 첫 화면 인트로. 홍보 영상에는 적용하지 않는다.
- 연출(2026-10-21 최종 수정): 샘플과 똑같이 구현한다. 검은 화면을 캐릭터가 왼쪽에서 오른쪽으로 밀어내고, 밀린 자리에 흰 바탕과 빨간 이름이 드러난다. 이름 "HUY PHAN"만 "대산"으로 바꾸고, 캐릭터는 대산 반장(노란 안전모·조끼·장갑)으로 그린다.
- 폐기한 안: 두 짝 미닫이 창·"탁탁" 효과, 백지가 걷히고 차콜 문구가 드러나는 안.
- 구현: HTML/CSS/SVG + Web Animations. 영상 파일·Lottie는 쓰지 않는다.

- 처음 목표였던 3초보다 길다. 샘플 재현을 우선했으며, 건너뛰기로 언제든 끊을 수 있다.

## 4. 동작 규칙

1. 같은 방문(브라우저 세션)에서 첫 진입 때 한 번만 재생한다. 재방문·새로고침 시 생략.
2. 화면 클릭·탭, 키보드(Esc/Enter/Space), "건너뛰기" 버튼으로 즉시 메인으로 간다.
3. 기기의 "동작 줄이기" 설정이 켜져 있으면 창을 그리지 않고 0.3초 페이드만 한다.
4. 메인 내용은 인트로 아래에 처음부터 DOM으로 존재한다. 검색 노출·첫 화면 속도에 영향이 없어야 한다. 인트로 층은 `aria-hidden`이며 끝나면 제거한다.
5. 메인 버튼은 인트로가 끝난 즉시 누를 수 있다. 인트로 종료가 어떤 이유로 실패해도 8초 후 강제로 걷는다.
6. 모바일도 좌우 열림. 창짝은 세로 화면 비율을 따른다. 손잡이·문구 크기만 줄인다.

## 5. 시각 기준

- 색: 화이트 #FFFFFF, 차콜 #222828, 딥그린 #23433A(상담 버튼), 골드 #E8B45F(문구 강조 1곳) — `B2B_SITE_PLAN.md` 색 제안을 따른다.
- 인트로: 검은 판 #0B0B0B, 드러나는 바탕 #FFFFFF, "대산" 빨강 #E0625A(샘플 이름 색), Noto Serif KR 700.
- 글꼴: Noto Sans KR.
- 메인 대표 사진: 사용 권한 확인된 실제 LX 시공 사진 확보 전까지 시안에서는 "대표 시공 사진 자리" 표시가 있는 회색 그라데이션을 쓴다. 생성 이미지를 실제 시공으로 게시하지 않는다.

## 6. 범위 밖

- 효과음, 홍보 영상 오프닝, 창·문 형태 묘사. 반장 캐릭터는 시안용 단순 SVG이며 정식 일러스트는 별도 작업.
- 실제 1차 사이트 구현·배포. 이번 산출물은 단독 HTML 시안 1개다.

## 7. 검증

- PC(1440px)·모바일(375px)에서 타임라인 구간별 화면 캡처로 확인.
- 건너뛰기·재방문 생략·동작 줄이기 대체가 실제로 작동하는지 확인.
- 확인 못 한 항목(실제 기기 성능, 사진 적용 후 느낌)은 남은 일로 기록한다.
