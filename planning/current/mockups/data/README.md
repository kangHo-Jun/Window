# 시공 사례 추가 방법

## 납품 현장 기록 (사진 없음)

- `supply-log.js`는 `/Users/zart/Projects/창호/대산 기존 창호 성과정리.xlsx`에서 자동으로 만든다. 엑셀을 고친 뒤:
  ```bash
  python3 build_supply_log.py
  ```
- 금액·업체 이름·비고는 내보내지 않는다. 업체는 A·B… 기호로만 세어 '2개 이상 현장을 맡긴 업체' 수를 낸다.
- 새 현장이 생기면 스크립트가 멈추고 알려 준다. `build_supply_log.py`의 `SITES` 표에 화면 이름·지역·유형을 한 줄 추가한다.
- 지역·유형은 엑셀 현장명에 드러난 것만 쓴다. 모르면 지역은 비우고(화면에 안 나옴) 유형은 '기타'.

## 사진 있는 사례

페이지: `mockups/cases.html` · 사례 목록: `mockups/data/cases.js` · 사진: `mockups/media/cases/`

## 사례 1건에 받을 자료

- 사진: 전체 1장(카드 표지), 디테일 2~3장, 시공 전(있을 때만). 동·호수, 사람 얼굴, 집 안 개인 물건이 보이지 않게 한다.
- 현장 이름·평형·현장 유형(아파트·빌라/연립·단독주택·상가)
- 제품 종류와 모델명(예: 발코니창 F-265, 분합창 F-230W)
- 작업 범위, 대산이 맡은 일(납품·실측·자재 함께 공급 등), 공정 기간
- 함께한 업체 이름은 그 업체가 게시에 동의한 경우만
- 집주인·업체의 사진 게시 동의

## 넣는 순서

1. 사진을 줄여 `media/cases/`에 넣는다. 가로 1000px(표지)·720px(나머지), JPG. 맥 터미널:
   ```bash
   sips -s format jpeg -s formatOptions 72 --resampleWidth 1000 원본.jpg --out media/cases/현장이름-cover.jpg
   ```
2. `data/cases.js` 맨 위 '대산 사례 양식'을 복사해 목록 맨 위에 붙이고 칸을 채운다.
   이미 목록에 '사진·세부 내용 준비 중'으로 있는 현장(잠실 리센츠 등)이면 그 줄을 지우고 새로 채운 것으로 바꾼다.
3. `cases.html`을 새로 고쳐 확인한다. 사진이 있는 대산 사례는 LX 사례보다 앞에 '대산 시공' 표시로 나온다.

## 자동으로 되는 것

- 필터 버튼은 사례에 있는 값으로 만들어진다. 대산 사례가 생기면 '대산 시공 / LX 공식 사례' 버튼이 나타난다.
- 사진이 없거나 `draft: true`인 대산 현장은 아래 '대산이 함께한 현장' 목록에 이름만 나온다.
- `cases.html#사례id` 주소를 보내면 그 사례가 펼쳐진 채로 열린다.
- LX 사례에는 'LX 공식 사례' 표시와 원 시공업체, '대산의 시공 현장이 아닙니다' 안내가 붙는다.
