# 상담 신청 → 구글 시트 접수

작성: 2026-10-26

홈페이지 '상담 신청' 폼에서 보낸 신청이 구글 시트에 한 줄씩 쌓인다.

- 접수 시트: [대산 상담 신청 접수](https://docs.google.com/spreadsheets/d/1BvZyADFXEMTryuoRD2Cg65r5r-vyLE2C3ioiYnJEmS8/edit) (zartkang@gmail.com 드라이브, 2026-10-26 생성). 사용자가 따로 만든 빈 시트 [상담고객](https://docs.google.com/spreadsheets/d/18khC2Yll7vwTLc4kvSvet0cCsrr8tSEvlmFGiqStPeU/edit)에 붙여도 된다 — 비어 있으면 첫 신청 때 제목 줄을 자동으로 넣는다
- 열: 접수 시각 · 연락처 · 이름·업체명 · 현장 지역 · 관심 내용 · 문의 내용 · 개인정보 동의 · 접수 화면 · 처리 상태 · 담당자 · 메모
  - 앞 8칸은 자동으로 채워진다. 처리 상태는 '신규'로 들어오고, 직원이 '연락함'·'완료' 등으로 바꿔 쓴다.
- 접수 프로그램: `Code.gs` (Apps Script)
- **운영 중인 시트: 상담고객** (2026-10-26 배포·실접수 확인)
- 홈페이지 쪽: `mockups/window-intro-prototype.html`의 `SHEET_ENDPOINT` 상수

## 배포 순서 (구글 계정 주인이 한 번만)

1. 위 시트를 연다 → 메뉴 **확장 프로그램 > Apps Script**.
2. 편집기의 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs`를 통째로 붙여넣는다. 저장(⌘S).
3. (선택) 새 신청 알림 메일을 받으려면 맨 위 `NOTIFY_EMAIL = ''` 따옴표 안에 받을 주소를 넣는다.
4. 오른쪽 위 **배포 > 새 배포** → 톱니바퀴에서 **웹 앱** 선택.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (로그인하지 않은 방문자도 신청할 수 있어야 한다)
5. **배포** → 권한 확인 창이 뜨면 본인 계정 선택 → '고급' → '(안전하지 않음)으로 이동' → 허용.
   본인이 만든 스크립트라 구글이 검사하지 않았다는 뜻이다. 허용 범위: 이 시트에 쓰기, (알림을 켰다면) 본인 계정으로 메일 보내기.
6. 끝에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 Claude에게 전달한다.
7. 확인: 그 주소를 브라우저로 열면 `{"ok":true,"service":"daesan-consult"}`가 보인다.

## 홈페이지에 연결

- 받은 주소를 `SHEET_ENDPOINT`에 넣는다. 비어 있으면 폼은 시안 안내만 보여 준다.
- 파일을 고치지 않고 시험: `http://localhost:8765/window-intro-prototype.html?sheet=웹앱주소#contact`
- claude.ai 비공개 게시본은 외부 주소로 보내는 것이 막혀 있어 실제 접수가 되지 않는다. 로컬 시안이나 실제 호스팅에서만 동작한다.

## Code.gs를 고친 뒤

배포 > **배포 관리** → 연필 → 버전 '새 버전' → 배포. 이렇게 하면 주소가 그대로 유지된다. '새 배포'를 누르면 주소가 바뀐다.

## 들어 있는 안전장치

- 연락처 숫자 9~12자리, 개인정보 동의가 없으면 저장하지 않는다(홈페이지에서도 같은 검사).
- 사람에게 보이지 않는 칸(`website`)이 채워진 요청은 자동 입력 프로그램으로 보고 저장하지 않는다.
- `=`, `+`, `-`, `@`로 시작하는 입력은 수식으로 실행되지 않게 글자로 저장한다. 연락처는 앞자리 0이 사라지지 않게 글자로 저장한다.
- 동시에 들어온 신청이 겹쳐 쓰이지 않게 잠금을 건다. 글자 수 제한(문의 내용 2,000자).

## 공개 전 남은 일

- **개인정보 수집·이용 안내문**: 수집 목적(상담 연락), 항목(연락처·이름·지역·문의 내용), 보관 기간(예: 상담 완료 후 1년), 동의 거부 시 상담 신청 불가 안내. 폼의 '자료 준비 중' 자리에 넣는다.
- 보관 기간이 지난 줄은 시트에서 직접 지운다(자동 삭제는 아직 없음).
- 시트 공유 범위: 상담 직원만 '편집자'로 공유한다. 링크 공유를 켜지 않는다.
