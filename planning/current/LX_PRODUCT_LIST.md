## 4. 사용 전 확인

1. **이미지 사용 권한:** 위 이미지는 LX Z:IN 저작물이다. 대리점·판매점이 홈페이지에 써도 되는 범위(출처 표기, 원본 제공 여부, 다른 서버에서 직접 불러와도 되는지)를 LX 담당자에게 확인하고, 가능하면 원본 파일을 받는다. 확인 전에는 홈페이지에 넣지 않는다.
2. **CB90·CB100:** 정식 명칭·제조사·이미지 확인.
3. **취급 범위:** 위 모델을 대산이 실제로 모두 공급하는지, 색상(창호도우미 래핑 13색)·유리 사양 중 실제 제공 범위.
4. **화면 문장:** 2절의 근거 문장 범위 안에서 제품 카드 '설명'과 '주요 특징'을 쓴다. 단열·기밀 성능 수치는 공식 수치 자료 없이 쓰지 않는다.
