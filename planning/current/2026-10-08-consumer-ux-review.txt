- 컴퓨터 유즈로 챗봇 질문→가격 카드→최종 결과→방문 상담 입력창, 직접 입력 4단계 확인.
- 시험 입력: 아파트, 30평대, 확장형, 안방 중형 한 곳, 20년이상, 결로, 시공 미정 후 1~3개월.
- 연락처 등 실제 개인정보 입력 및 상담 접수는 하지 않음.
- 로컬 개발 HEAD 98e3fe4의 page, FormSelector, QuoteFormLego, ConsultationForm, OperatorReport, QuoteResult 및 PRD v4 참고.
- 운영 헤더는 SYNC, 로컬 헤더는 (주)대산으로 달라 동일 버전이라고 간주하지 않음. 과거 로컬 계산 검증 수치와 이번 운영 관찰을 구분.
- UI·UX 스킬 기준 참조. 사용자 조사·전환율 실험·모바일 및 키보드 전체 검수는 미수행. 이하 전환 효과는 전문가 판단이며 실측 성과가 아님.

1. 의도 해석
소비자의 교체 필요성과 예산 불안을 줄여 대산의 전문 상담·실측으로 연결하는 서비스다. 고객은 제품 코드보다 '교체할 필요가 있는지, 무엇을 바꾸면 되는지, 대략 얼마인지, 누가 책임지는지'를 먼저 알고 싶어 할 것으로 본다.
PRD는 AI를 근거 있는 상담 전문가, 코드를 가격 계산기로 분리하고 있다. 이 의도는 적절하지만 실제 UX는 정보 수집·브랜드 추천·판매자 내부 전략·정밀도 표현이 혼재한다.

2. 유지할 장점
- 치수를 모르는 소비자가 주거형태·평형·확장 여부부터 시작할 수 있음.
- 버튼 중심의 대화와 직접 입력 선택지를 제공.
- 교체 공간 선택으로 일부 교체 의도를 표현 가능.
- 입력 요약 및 가견적을 대화 중 확인 가능.
- 주소를 동 단위로 입력할 수 있어 상담 초기 부담을 줄임.
- 추가 정보로 단계적으로 구체화하려는 방향은 유지할 가치가 있음.

3. 실제 관찰한 우선 문제

P0 고객 화면에 내부 영업 전략 노출
- 결과에 '상담사 전략 노트', '견적 완성도 높음 — 방문 상담 전환 시도', 우선순위 중 표시.
- 고객은 도움을 받는 사람보다 영업 대상으로 분류된다고 느낄 수 있음.
- 판매자 전략·분류·우선순위를 운영자 화면으로 분리. 고객 화면에는 요청 요약과 다음 확인 사항 표시.

P0 금액 변화와 정밀도 설명 불일치
- 안방 중형 선택 후 LX 약 196만원, KCC 147만원, 기타 103만원.
- 시공 시기 1~3개월 입력 후 LX 587만원, KCC 441만원, 기타 308만원으로 변경. 결과의 교체 공간은 여전히 안방.
- 최종 LX 5,872,500원. UI에는 변화 근거·수량 변화 설명 없음. 내부 원인은 이번 UI 평가에서 확정하지 않음.
- 가견적 버튼 ±30%, 우측 카드 ±10%; 다음 레벨에서도 버튼 ±15%, 카드 ±10%로 불일치.
- 수량·사양·포함 항목이 바뀌면 변화 내용을 설명하고, 근거 없는 정밀도 약속은 피해야 함.

P0 절감 효과의 불일치
- 연식 답변 전 '10년 이하 30평대 기준 연 7만원' 표시.
- 연식 20년이상 선택 후 연 18만원.
- 최종 화면에 연 18만원 문구와 별도 계산기의 234,900원이 함께 표시.
- 추정에 사용한 조건을 공개하고 같은 데이터·계산을 사용해야 함. 사용자 미입력 값을 확정 사실처럼 표시하지 않음.

P1 상담보다 빠른 추천
- 노후도·불편 답변 전부터 LX 추천과 장기 효율 문구 표시.
- '결로' 선택 후 추가 원인 질문 없이 바로 시공 시기로 넘어감.
- 해당 시험 경로에서는 결로 위치·발생 상황·사용 환경을 충분히 묻지 못함.
- 증상별 핵심 후속 질문을 짧게 추가하고 진단 한계를 설명. 제품 추천 이유를 고객 응답과 연결.

P1 비교 서비스와 LX 판매 상담의 관계 불명확
- 입구는 LX·KCC·기타 비교를 약속하지만 추천은 초반부터 LX.
- 비교 결과는 프리미엄/중간/실속과 가격 중심. '기타'는 구체 제조사·제품이 없어 동일 조건 비교인지 판단 어려움.
- 대산의 역할과 비교 목적을 명확히 설명. 브랜드 이름보다 동일 범위의 제품·유리·시공·보증 조건을 비교.

P1 진행 안내와 실제 완료 기준 불일치
- 상단 10개 항목/레벨 0~3, 우측 수집 7개, 3개 기본 정보 후 첫 견적 예고.
- 실제 시험에서는 공간까지 선택한 4개 시점에 첫 카드가 나타남.
- 7개 답변 후 '모두 파악' 안내와 최종 결과. 상단은 70% 상태였음.
- '미정' 버튼 선택 시 시공 시기 질문 반복. '1~3개월' 선택 후 진행.
- 고객에게 보이는 완료 기준을 하나로 통일하고 미정도 정상적인 답으로 처리.

P1 고객의 언어와 선택 기준 부족
- '레고식', '레벨', '수집 0/7', 'ESTIMATE STATUS'는 서비스 내부 표현.
- 공간별 소·중·대에 치수 또는 사진 기준이 보이지 않음.
- 직접 입력도 치수 입력 방식이 아니라 평형별 표준 창 구성을 불러와 수량 조절.
- '질문에 답하며 알아보기', '교체할 창 직접 고르기' 등 실제 행동을 설명하는 이름이 적절.
- 표준 치수는 고객 집의 확정 치수와 구분하고 '모름'을 제공.

P1 상담 신청 약속 부족
- 이름·연락처·주소·희망일 요청. 화면에는 연락 시점/상담 절차/방문 확정 여부 설명이 부족.
- 전화 링크는 010-0000-0000. AI가 'LX지인 창호 전문가(10년차)'라고 표시.
- 실연락처, 대산의 실제 역할, AI 안내, 접수 후 다음 행동을 사실에 맞게 정리.
- 개인정보 처리 목적 등 안내를 사용자 이해 관점에서 보강할 필요. 법적 적합성 판단은 수행하지 않음.

P2 시각·접근성
- 데스크톱 캡처에서 좁은 대화 영역과 상태 패널이 나란히 배치되어 진행 지표·빈 상태 정보의 비중이 큼.
- 초기 화면에서 상담 진행도와 우측 수집 현황이 중복. 고객 질문과 답변을 우선하고 요약은 접을 수 있는 구조를 권고.
- 유사 버튼 중복: 20년이상/20년 이상, 결로/결로·곰팡이, 6개월이후/6개월 이후.
- '아파트님', '30평대평' 문구 확인.
- 직접 입력 선택 카드가 DOM에서 일반 요소로 노출되고, 로컬 구현은 onClick div. 수량 +/- 버튼의 접근 가능한 이름 없음.
- 명도 대비 수치, 모바일 터치 크기, 키보드 전체 사용성은 별도 검증 필요. 확인하지 않은 항목을 실패로 단정하지 않음.

4. 참고 LX 9단계 사이트와 연결
소비자 입구에는 쉬운 사용 목적 질문을 유지하고, 상세 사양은 후속 상담에서 활용하는 것이 적합하다고 판단한다.
- 소비자: 위치·불편·교체 범위·대략 크기/모름·지역·일정
- 상담자: 모델, 단창/이중창, 개폐 모양/W1, 유리 조합, 색상, 배수홀, 방충망, 손잡이
- 견적 담당: 실측·적용 가능 여부·공급/시공 범위·단가·현장 추가비
9단계 전체를 초기 소비자 필수 질문으로 옮기면 전문지식 부담을 늘릴 수 있다. 그 사이트의 '미정 항목을 상담 과제로 남기는 방식'을 우선 참고한다.

5. 권장 소비자 흐름
1) 첫 화면: 누구를 위한 서비스인지, 얻는 결과와 실측 전 예산 안내임을 설명
2) 목적: 추위/소음/결로/노후/교체 계획부터 파악
3) 범위: 전체/일부, 공간을 그림으로 고르고 위치·크기를 모르면 미정 허용
4) 꼭 필요한 조건만 추가 질문. 증상에 따른 짧은 후속 질문
5) 결과: 내가 선택한 창과 가정한 사양, 예산 범위, 포함/미포함, 변동 요인, 추가 확인 사항
6) 상세 사양 선택은 원하는 사람에게 제공
7) 전화/사진 검토/방문 등 실제 제공 가능한 상담 다음 단계를 명확히 안내
8) 상담자는 기존 응답과 미정 목록을 받아 고객에게 같은 질문을 반복하지 않음

6. 실행 순서
우선: 고객 화면 내부 전략 제거, 가격·수량·오차·절감 수치 일관성, 실제 연락처 및 미정 처리.
다음: 서비스 약속·비교 기준·결과 화면 정보 구조, 답변 수정/견적 변화 설명.
그다음: 증상별 상담과 후속 상세 사양 연결, 모바일·키보드·대비 검증.
마지막: 실제 소비자 테스트로 질문 이해도, 완료율, 수정 빈도, 견적 이해, 상담 신청 의향을 확인.
이번에는 평가 기록만 작성했고 앱 코드·배포는 수정하지 않았다.
