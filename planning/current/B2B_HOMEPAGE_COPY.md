# 대산 1차 홈페이지 문구와 자료 준비표

작성: 2026-10-26 (같은 날 문구 방향 확인 반영)
상태: 메뉴·본문 구성 사용자 승인. 문구 방향(독자·선택 이유·LX 장점 위치·톤) 사용자 확인 후 메인·제품 소개·시공 사례·대산 소개 문구 수정. 아래 문구는 검토용 원고이며 제품·사례·운영 조건 확인 후 공개용으로 확정한다.
범위: 문구와 자료 정리만. 웹사이트·시안·코드·배포 작업 없음. 기존 인트로 자산 보존, 별도 2차 AI 개발 중단 유지.
기준: [1차 구성안](B2B_SITE_PLAN.md) 9절. 대괄호는 내부 채움 표시이며 그대로 게시하지 않는다.

**문구 방향 (2026-10-26 사용자 확인)**
- 주 독자: 인테리어 업자. 메인은 업자 말투를 유지하고, 일반 소비자 안내는 FAQ·상담 구간에서 한다.
- 대산을 고를 이유: **현장 자재 한 번에 구매**, **창호 전담 직원 응대** 두 가지를 앞에 세운다. 35년 업력은 뒷받침으로 둔다. 납기·배송·결제 조건은 확인 전이므로 쓰지 않는다.
- LX 창호 장점(확 트인 뷰·넓어진 공간감·고급 디자인·밝은 실내): **제품 소개 구간에만** 쓴다. 메인은 대산 서비스 중심.
- 톤: 담백하되 구간마다 가치를 한 줄 보인다. 설명 문장마다 "상담하세요"를 반복하지 않고 상담 권유는 버튼이 맡는다.
- 버튼 이름은 "창호 상담 신청"으로 통일한다(인트로 시안의 "창호 구매 상담"도 이후 이 이름으로 맞춘다).

## 0. 상단 메뉴

대산 로고 | LX 창호 | 시공 사례 | 대산 소개 | **창호 상담 신청**

필요 자료: 대산 로고 원본, 정확한 브랜드 표기, LX 상표·공식 이미지 사용 가능 범위. 메뉴는 본문 해당 구간으로 연결하고 제품·사례만 상세 자료 연결을 준비한다.

## 1. 창호 메인

**설명**
창호는 전담 직원이 상담하고, 현장 자재는 한곳에서 함께 준비하세요. 실측과 견적까지 대산이 안내합니다.

**버튼**
창호 상담 신청 / 시공 사례 보기

**필요 자료**
- 실제 취급 창호를 보여주는 대표 사진과 사용 권한. 기존 인트로 자료의 최종 사용 여부는 별도 작업 기준을 유지한다.
- LX 완성창 취급 관계와 제품 표기 확인 자료.
- 사진이 실제 현장인지 공식 제품 예시인지 구분. 생성 영상·목업을 대산 실제 시공 실적으로 표시하지 않는다.

## 2. LX 제품소개

**제목**
현장에 맞는 LX 창호를 만나보세요.

**설명**
넓은 유리와 슬림한 프레임으로 시야는 시원하게, 실내는 더 밝게. 설치할 공간에 맞는 제품을 살펴보세요.

**LX 창호의 장점** (제품 카드 위 3개 블록)

| 블록 | 제목 | 한 줄 설명 | 공개 전 확인 |
|---|---|---|---|
| 1 | 확 트인 뷰 | 프레임은 얇게, 유리 면은 넓게. 창밖 풍경이 그대로 들어옵니다. | 슬림 프레임 해당 모델·수치 근거 |
| 2 | 넓어진 공간감 | 밝게 드는 햇빛과 시원한 개구부로 거실이 더 넓어 보입니다. | 하부 레일 매립 등 구조 표현은 해당 모델만 사용 |
| 3 | 고급스러운 디자인 | 공간에 어울리는 프레임 색상과 깔끔한 마감. | 실제 판매 색상·마감 목록 |

- 위 문장은 LX 공식 자료로 근거가 확인된 표현만 공개한다. 단열·기밀·소음 등 성능 수치는 공식 근거 없이 넣지 않는다.
- 장점 블록의 사진은 공식 이미지 사용 범위 또는 실제 현장 사진으로 채우며, 생성 영상·렌더 이미지를 실제 제품 사진처럼 쓰지 않는다.

**제품별 표시 원고 양식**
- 제품명: [실제 취급 모델명]
- 적용 공간: [공식 자료와 취급 범위로 확인한 공간]
- 설명: [확인된 제품 특징을 한 문장으로 작성]
- 주요 특징: [공식 근거가 있는 특징 2~3개]
- 버튼: 제품 자세히 보기 / 이 제품 상담하기

**필요 자료**
실제 판매 모델 목록, 최신 공식 카탈로그, 모델별 이미지, 적용 공간, 선택 사양, 성능·보증 표시의 근거 및 조건. 자료 확보 전 임의의 모델·성능 수치를 채우지 않는다. 제품 목록 확정 후 카드별 설명 문장을 완성한다.

## 4. ALL IN ONE 구매 혜택

**작은 제목**
ALL IN ONE

**제목**
창호 구매도, 현장 자재 준비도. 대산에서 한 번에.

**설명**
대산에서 LX 창호를 구매하시면, 같은 공사에 필요한 목자재·기초자재를 10% 할인해 드립니다.

**혜택 표시**
같은 공사 건의 목자재·기초자재 10% 할인

**조건 안내 초안**
창호 금액은 할인 대상에서 제외됩니다. 대상 품목과 적용 조건은 상담 시 확인해 주세요.

**버튼**
창호·자재 함께 상담하기

**필요 자료 / 추후 확인**
대상·제외 품목, 할인 기준 가격, 적용 시점, 동일 공사 확인 방식, 다른 혜택 중복 여부, 담당자용 안내표. 사용자가 추후 확인하기로 한 항목이므로 지금 답변을 요구하지 않는다. 공개 전 실제 조건을 정리하고 위 안내에 반영한다. ‘상담 시 확인’ 문구만으로 미확정 조건이 해결된 것으로 취급하지 않는다.

목자재 사진은 필수 자료가 아니다. 전체 취급 품목에 무조건 10% 할인되거나 창호 자체를 할인하는 것으로 표현하지 않는다.

## 5. 대산 소개·상담 안내

### 5-1. 대산 소개

**제목**
창호 상담은 전담 직원이, 현장 자재는 한곳에서.

**설명**
LX 창호는 창호 전담 직원이 처음부터 실측 연결까지 맡아 상담합니다. 같은 현장에 필요한 목자재, 단열재, 도어, 석고보드도 대산에서 함께 준비할 수 있습니다. 35년간 건축자재를 판매해 온 대산이 함께합니다.

**보조 문구**
창호 전담 직원 상담 · 현장 자재 함께 구매 · 35년 건축자재 판매 경험

**수정 메모 (2026-10-26)**
대산을 고를 두 가지 이유(전담 직원·자재 한 번에)를 제목과 첫 문장에 세우고, 35년은 뒷받침으로 내렸다. 이전 제목 "35년간 건축자재를 판매해 온 대산, 이제 LX 창호도 함께하세요."는 대안으로 보관한다.

**필요 자료**
업력 확인 가능한 연혁·자료, 매장/창고 사진 2~3장 권장, 정확한 취급 품목, 전담 직원 소개 및 사진 사용 동의(사진은 선택). ‘이제’는 창호 취급 개시 시점을 주장하는 연혁 문구가 아니라 소개 표현이며 필요하면 생략한다. 영림도어 전국 1위는 증빙 전 원고에 넣지 않는다. 35년은 창호 제조·시공 경력으로 표시하지 않는다.

### 5-2. 상담에서 안내할 내용

**제목**
창호 선택부터 실측 준비까지, 필요한 내용을 함께 확인합니다.

**설명 초안 — 상담 자료 준비 후 사용**
현장에 맞는 제품 자료와 참고 사례를 살펴보고, 실측을 진행하려면 무엇이 필요한지 안내해 드립니다.

**필요 자료**
전담 직원이 실제 전달할 제품 자료 묶음, 사례 링크, 실측 준비 안내. 모든 현장과 동일한 사례를 제공하거나 상담 중 확정 가격을 산출한다고 약속하지 않는다.

### 5-3. 진행 절차

**제목**
상담부터 주문까지, 이렇게 진행됩니다.

1. **창호 상담** — 현장 상황과 필요한 창호를 전담 직원과 상의합니다.
2. **실측 요청** — 실측을 원하시면 진행 가능 여부와 일정을 협의합니다.
3. **현장 실측** — 협력업체가 현장을 방문해 치수와 현장 조건을 확인합니다.
4. **견적 안내** — 실측 내용을 바탕으로 견적서를 안내합니다.
5. **주문 진행** — 제품과 견적 내용을 확인한 뒤 주문을 진행합니다.

**보조 문구**
상담 신청만으로 실측 일정이나 주문이 확정되지는 않습니다.

**필요 자료**
서비스 지역, 실측 비용·조건, 일정 협의 방식, 견적 발행 주체·제공 시점, 주문 안내 절차. 설치·하자 문의의 역할 분담도 별도로 확인한다. 무료·당일·즉시·전국 서비스는 확인 전 사용하지 않는다.
